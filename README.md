## I build beyond the demo

I work where machine learning meets systems engineering. A model output is only the beginning: the result must be calibrated, governed, tested, traceable, deployable and understandable to the person using it.

My strongest work combines scientific computing, full-stack product design and explicit evidence. I care about the failure path as much as the happy path—and I would rather refuse an unsupported claim than disguise uncertainty as confidence.

## How I think

```text
ambitious idea
    → explicit requirements
    → architecture with failure boundaries
    → implementation tied to evidence
    → adversarial verification
    → honest release
```

- **Truth before theatre:** status, confidence and limitations should match the evidence.
- **Fail closed:** unsupported scientific, privacy or deployment claims stay locked.
- **Design and rigor belong together:** a reliable system should also feel clear, fast and deliberate.
- **Ship the whole path:** model, backend, interface, packaging, validation and recovery are one product.
